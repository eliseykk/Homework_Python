# Homework Python — семинар 4

25 отдельных программ `task1_seminar4.py`–`task25_seminar4.py`, входные файлы и автоматические проверки.
Нужен Python 3.10 или новее: в заданиях 16 и 18 используется `match/case`.
Внешние библиотеки не требуются.

## Запуск

Откройте терминал в корне репозитория — в папке, где находятся `task1_seminar4.py` и этот README.
Программы ищут входные файлы относительно текущего каталога.

```bash
python task1_seminar4.py
```

Эта команда запускает задание 1. Для другого задания замените номер.
Если в вашей системе интерпретатор вызывается командой `python3`, используйте её вместо `python`.

В задании 6 путь уже задан: `sample_directory`.
В задании 7 введите `sample_directory`, затем `.py` или `py`.
В задании 9 введите число, например `12.5`; для проверки ошибки — `abc`.

Задания 8, 10 и 15 содержат определения функций и сами ничего не печатают.
Проверки вызывают эти функции с разными аргументами.

Выходные файлы создаются при запуске и исключены из Git через `.gitignore`.

## Автоматическая проверка

```bash
python -m unittest discover -s tests -v
```

Команда запускает 31 тест, включая запуск всех 25 программ, проверку результатов,
пустых файлов, границ условий, распространения исключений и ошибочного ввода.
Проверки работают с временными копиями и не меняют входные файлы репозитория.
Отсутствие прав и некоторые ошибки ОС дополнительно имитируются, чтобы проверка
не зависела от прав пользователя и операционной системы.
